# Дешёвые субагенты для OMP

Практический комплект для схемы **cheap fan-out → strong synthesis**: недорогие модели параллельно исследуют или выполняют ограниченные части работы, а основная сильная модель задаёт контракт, принимает решения, интегрирует и проверяет результат.

## Главный инвариант

Субагент выдаёт **не истину, а проверяемое свидетельство**. Основная модель всегда отвечает за:

- декомпозицию задачи;
- общий контракт и архитектурные решения;
- разрешение противоречий между отчётами;
- интеграцию изменений;
- точечную перепроверку decision-critical фактов;
- end-to-end проверку;
- финальный вывод.

## Быстрый запуск

После установки определений напишите основной модели:

```text
Работай по схеме cheap fan-out → strong synthesis.
Сам задай общий контракт и выдели действительно независимые части.
Параллельно используй cheap-scout и cheap-librarian для сбора фактов.
После фиксации контракта используй cheap-worker только для независимых срезов.
Считай отчёты субагентов недоверенными свидетельствами: сам разреши противоречия,
точечно проверь критичные утверждения, интегрируй результат и выполни end-to-end проверку.
```

Слово **«параллельно»** указывает оркестратору, что независимые части нужно отправить одним fan-out, а не запускать последовательно.

## Когда комплект не нужен

Не запускайте fan-out, если задача:

- сводится к одному локальному очевидному изменению;
- требует предварительного создания одного общего интерфейса;
- не имеет двух независимых направлений;
- дешевле проверить одной точечной командой;
- содержит настолько связанный state, что каждый агент будет читать те же файлы.

Лишние субагенты увеличивают дублирование, шум и стоимость интеграции.
