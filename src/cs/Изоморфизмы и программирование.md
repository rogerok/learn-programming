
## Биекция

**Биекция** - перевод между двумя представлениями, который можно полностью обратить.
Отношение один к одному между двумя множествами: каждому элементу слева отвечает ровно один элемент справа и наоборот. 
Биекция обратима, у неё есть функция-инверсия.

Биекция между типами `T` и `U` это пара функций
`to: T => U` и `from: U => T`

```ts
type Toggle = 'on' | 'off'

const toBoolean = (value: Toggle): boolean => value === 'on';

const fromBoolean = (value: boolean): Toggle => value ? 'on' : 'off'

```

Соответствие один к одному:

'on'  ↔ true
'off' ↔ false

```ts
  fromBoolean(toBoolean('on')); // 'on'
  toBoolean(fromBoolean(false)); // false
```

### Пример без биекции

```ts
const normalizeEmail = (email: string) => email.trim().toLowerCase();
normalizeEmail('USER@mail.com');
normalizeEmail(' user@mail.com ');
```
Вернуть исходную строку невозможно. Значит, это не
биекция.
