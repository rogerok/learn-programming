# CSS — диагностика и модернизация

## Роль раздела

Это короткий учебный маршрут вокруг source-based заметки о современных CSS-сокращениях и layout primitives. Заметка служит reference material, а не списком безусловно «плохих» техник: замену нужно выбирать по семантике layout и проверять в браузере.

## Предварительные знания

- cascade и computed styles;
- normal flow, `position: absolute` и `position: fixed`;
- основы Grid и Flexbox;
- физические и логические направления в CSS.

**Входной check:** для одного элемента объясните разницу между normal flow и absolute positioning и назовите, относительно какого box вычисляется его положение. Если ответ нельзя проверить через DevTools, сначала повторите positioning.

## Наблюдаемый результат

После маршрута вы можете сравнить legacy и modern CSS не по длине записи, а по layout contract: указать сохранённые инварианты, выбрать counterexample для слишком широкой замены и составить проверяемую browser matrix для modernization.

## Маршрут

1. Прочитайте [[эти-css-техники-устарели|исходную заметку]] и для каждой предложенной замены выпишите условие, при котором поведение действительно сохраняется.
2. Выполните [[упражнения-диагностика-и-модернизация|набор упражнений]] по порядку: `predict → explain → diagnose → transfer`.
3. Вернитесь к source note и пометьте каждую технику как `эквивалент`, `эквивалент при условии` или `другое layout decision`.

**Проверка завершения:** у вас есть таблица из пяти техник, и в каждой строке указаны исходный intent, условие замены и одно наблюдение в DevTools или screenshot comparison. Формулировка «modern короче» без проверки поведения не считается результатом.
