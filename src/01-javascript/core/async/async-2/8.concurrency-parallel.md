# Конкурентность и параллелизм

**Асинхронность** - способ записи: операция не отдаёт результат, а обещает его потом.
**Конкурентность** - это про структуру. Несколько задач находятся в работе одновременном, их шаги чередуются.
**Параллелизм** - это про исполнение: несколько вычислений физически идут в один момент на разных ядрах

## Где помогает что

I/O-bound - тип нагрузки при которой программа большую часть времени ждёт внешний ресурс: сеть, диск, базу. Процессор почти простаивает.

**Помогает** конкурентность (event loop, async/await)

CPU-bound - задача, где большую часть времени программа выполняет вычисления: считает хэши, картинки, перемножение матриц.

**Помогает** параллелизм (worker_threads, cluster)

## Как это работает в Node

- async\await, Promise, event loop - инструменты конкурентности. Один по ток, чередование задач. Идеальны для I\O.
- worker_threads, параллелизм внутри процесса. Общий `SharedArrayBuffer` и обмен сообщениями. Для CPU задач, которые надо держать рядом с основным потоком
- cluster - параллелизм через форк процесса: несколько копий приложения делят один порт. Масштабирование под нагрузку.
- дочерние процессы, это параллелизм с полной изоляцией памяти, обмен через сокеты и pipe
