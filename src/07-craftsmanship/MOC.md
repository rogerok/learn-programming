# Мастерство программирования — Map of Content

## Цель

Научиться проводить code review небольшого фрагмента: восстановить его поведение, обнаружить проблемы в именах, связности и управляющем потоке, а затем предложить изменение, которое сохраняет проверяемый контракт. Результат обучения наблюдаем: вы можете сослаться на конкретное правило из конспекта, показать вход, ожидаемый выход и объяснить риск исходного решения.

## Пререквизиты

- Умение читать функции, классы, условия и циклы хотя бы на одном языке.
- Базовое понимание тестов и предусловий.
- Для сопоставления с принципами ООП: [[../03-oop/MOC|OOP]].

## Канонический маршрут

1. **Сделать данные читаемыми.** [[code-complete/3.vars/10.base-vars-usage|Базовое использование переменных]] → [[code-complete/3.vars/11.vars-naming|Именование переменных]].  
   **Проверка:** для трёх переменных объясните их назначение, область видимости и способ сократить время жизни; переименования не должны менять поведение.
2. **Ограничить ответственность функции.** [[code-complete/2.high-quality-code/7.methods|Проектирование методов]] → [[code-complete/2.high-quality-code/7.high-quality-methods|Параметры высококачественных методов]].  
   **Проверка:** сформулируйте одну ответственность метода и найдите параметр или действие, которое ей не соответствует.
3. **Спроектировать границу объекта.** [[code-complete/2.high-quality-code/6.classes|Классы]].  
   **Проверка:** по публичному API класса назовите его инвариант и один способ нарушить инкапсуляцию или Правило Деметры.
4. **Сделать порядок исполнения явным.** [[code-complete/4.operators/14.sequential-code-organization|Организация последовательного кода]] → [[code-complete/4.operators/15.if-operators|Условные операторы]] → [[code-complete/4.operators/16.loops|Циклы]].  
   **Проверка:** вручную проследите нормальный и граничный пути, включая первую, типичную и последнюю итерации цикла.
5. **Заменить сложное ветвление моделью правил.** [[code-complete/4.operators/18.table-methods|Табличные методы]] → [[code-complete/4.operators/19.general-control-issues|Общие вопросы управления]].  
   **Проверка:** составьте таблицу решений, отметьте приоритет пересекающихся правил и найдите комбинацию условий без определённого результата.
